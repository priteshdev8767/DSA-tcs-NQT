# 🚀 DSA-TCS-NQT

A complete collection of **Data Structures & Algorithms (DSA)** and **TCS NQT Coding Questions** solved in **C++**.

This repository is created to help students prepare for:

* TCS NQT
* TCS Prime
* TCS Digital
* Placement Coding Rounds
* Technical Interviews
* Competitive Programming Basics

---

## 📂 Repository Structure

### 🔢 Numbers

Problems based on:

* Palindrome Number
* Prime Number
* Armstrong Number
* Perfect Number
* Fibonacci Series
* Factorial
* GCD & LCM
* Sum of Digits
* Reverse Number
* Strong Number
* Happy Number
* Automorphic Number
* Harshad Number
* AP & GP Series
* Quadratic Equation
* Prime Factors
* Permutations & Combinations

### 📊 Arrays

Problems based on:

* Largest Element
* Second Largest Element

* Sum of Array
* Frequency Count
* Remove Duplicates
* Search in Array
* Maximum Product
* Sorting Arrays

---

### 🔤 Strings

Problems based on:

* Palindrome String
* Reverse String
* Anagram Check
* Character Frequency
* String Manipulation

### 🔄 Sorting

Algorithms covered:

### 🔢 Number System

Conversions:

* Decimal to Binary

* Decimal to Octal
* Octal to Decimal
* Binary to Octal
* Octal to Binary
* Number to Words
